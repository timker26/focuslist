# FocusList — план интерфейса

## Продуктовая идея

FocusList — персональный менеджер задач для iOS и Android. Он помогает быстро фиксировать дела, собирать их в понятные списки, видеть сроки в календаре и получать своевременные напоминания. Приложение рассчитано на портретную ориентацию 9:16 и управление одной рукой: главный плюс расположен в зоне большого пальца, а ключевые действия выполняются через короткие нижние панели.

## Экранная карта

| Экран | Содержание | Основные действия |
|---|---|---|
| Сегодня | Задачи на сегодня, просроченные задачи, краткая статистика и ближайшие сроки | Завершить задачу, открыть карточку, добавить задачу |
| Календарь | Месячная сетка с маркерами задач и список дел выбранного дня | Выбрать дату, просмотреть и открыть задачи |
| Списки | Системные и пользовательские списки с количеством незавершённых задач | Создать, переименовать и удалить список; открыть задачи списка |
| Настройки | Переключатель темы, статус уведомлений и справочная информация | Сменить светлую/тёмную тему, запросить разрешение на уведомления |
| Карточка задачи | Название, описание, список, дата и время срока, статус напоминания | Создать, редактировать, завершить или удалить задачу |
| Карточка списка | Название, цвет и список связанных задач | Создать, переименовать или удалить список |
| Организация | Папки, настраиваемые цветные теги и быстрые фильтры | Создать, изменить или удалить папку/тег; открыть связанные задачи |
| Архив | Завершённые задачи с датой выполнения и признаками категорий | Просмотреть, восстановить или окончательно удалить задачу |
| Поиск | Поле запроса по всем задачам, фильтры по тегам, приоритетам и статусу | Найти активную или архивную задачу, открыть её карточку |
| Статистика | Недельная диаграмма завершённых задач и итоги периода | Посмотреть динамику по дням и общий результат недели |

## Основные сценарии

Пользователь нажимает плавающую кнопку добавления на экране «Сегодня», вводит название задачи, выбирает список и срок, затем сохраняет её. Если указан срок, приложение планирует локальное напоминание. Выполненная задача отмечается одним касанием; экран даёт лёгкую тактильную обратную связь и обновляет счётчики.

Пользователь открывает «Календарь», выбирает нужный день и видит связанные с ним задачи. Тап по задаче открывает карточку для редактирования срока, текста или списка. В «Списках» пользователь создаёт тематические группы — например, «Работа» и «Личное» — и управляет ими из нижней панели.

Пользователь может создавать цветные теги, например «Важно», «Звонок» или «Покупки», и назначать несколько тегов одной задаче. Папка задаёт более крупный контекст, например «Проекты» или «Дом»; каждая задача может принадлежать одной папке. В разделе «Списки» пользователь выбирает папку или тег и сразу видит только связанные незавершённые задачи. При удалении тега он снимается с задач, а при удалении папки задачи остаются в приложении без папки.

Пользователь также может найти задачу по названию, заметке или тегу в разделе «Организация». Быстрые фильтры показывают важные задачи, задачи без папки и задачи без тегов. Для переноса между папками пользователь удерживает задачу на экране папки и выбирает новую папку в появившемся компактном меню; этот сценарий заменяет неточный drag-and-drop на маленьком экране более надёжным одноручным действием.

Для каждой задачи пользователь выбирает один из четырёх уровней: «Без приоритета», «Низкий», «Средний» или «Высокий». На главном экране доступны режимы сортировки по приоритету и по сроку; по умолчанию сохраняется привычная последовательность. При завершении задача уходит в архив, не смешиваясь с текущими делами. В архиве её можно восстановить одним касанием, после чего она снова отображается среди активных задач с сохранёнными сроком, папкой, тегами и приоритетом.

Глобальный поиск доступен на отдельной вкладке и охватывает активные и архивные задачи. Помимо запроса по названию, заметке и тегам, пользователь может быстро ограничить результаты конкретным тегом, приоритетом или статусом «Все», «Активные», «Архив». Экран статистики показывает последние семь календарных дней: высота каждого столбца отражает число задач, завершённых в этот день, а сводка выводит общий результат и лучший день недели.

При первом запуске приложение создаёт четыре готовые папки: «Дом», «Авто», «Работа» и «Личное». Они служат отправной точкой и остаются полностью настраиваемыми. Верхняя панель редактора задачи всегда размещается внутри безопасной области устройства, поэтому кнопки «Отмена» и «Готово» не перекрываются системным статус-баром на устройствах с вырезом или высоким статус-баром.

Папка получает выбираемый эмодзи вместо стандартной иконки. Пользователь может выбрать символ из визуальной палитры или ввести свой эмодзи. Самые важные папки можно закрепить: они отображаются вверху раздела «Организация» с небольшим маркером булавки, сохраняя порядок среди остальных папок.

Карточка папки показывает счётчик просроченных активных задач яркой контрастной плашкой. Для каждой папки пользователь выбирает одну из шести градиентных обложек; обложка помогает быстрее различать контексты задач. В открытой папке можно сохранять шаблоны с названием, заметкой, приоритетом и признаком важности, а затем создавать задачу из шаблона одним касанием.

## Визуальная система

| Область | Решение |
|---|---|
| Бренд | Спокойный индиго-акцент FocusList: `#4659E8`, который хорошо заметен на светлой и тёмной поверхностях |
| Светлая тема | Фон `#F7F8FC`, карточки `#FFFFFF`, основной текст `#182033`, вторичный текст `#697386` |
| Тёмная тема | Фон `#10131D`, карточки `#1A2030`, основной текст `#F4F6FF`, вторичный текст `#A9B1C5` |
| Семантические цвета | Успех `#2EAD75`, предупреждение `#EFA33C`, ошибка `#E35757` |
| Типографика | Системный шрифт San Francisco на iOS и Roboto на Android, крупные заголовки 30–32 pt, основной текст 15–17 pt |
| Компоненты | Скругления 18–24 pt, тонкие разделители, крупные зоны нажатия не менее 44 pt, ненавязчивые анимации 150–250 мс |

## Модель данных

| Сущность | Поля |
|---|---|
| Список | `id`, `title`, `color`, `createdAt` |
| Задача | `id`, `title`, `notes`, `listId`, `dueAt`, `completedAt`, `notificationId`, `createdAt` |
| Папка | `id`, `title`, `color`, `createdAt` |
| Тег | `id`, `title`, `color`, `createdAt` |
| Связь задачи с категорией | `folderId` и массив `tagIds` в задаче |
| Свойства задачи для планирования | `priority` (none/low/medium/high) и `archivedAt` после завершения |
| Настройки | `themeMode`, `notificationsEnabled` |

Данные хранятся локально на устройстве через AsyncStorage. Это сохраняет конфиденциальность и позволяет работать без учётной записи; синхронизация между устройствами не входит в текущий объём работ.
