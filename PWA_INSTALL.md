# FocusList без Expo Go: установка на Android

FocusList доступен как устанавливаемая веб-версия. Это самый простой вариант для личного использования на Android: не нужны Expo Go, APK, GitHub Secrets или сборка.

## Установка на Android

1. Откройте в **Google Chrome** адрес опубликованной веб-версии FocusList.
2. Нажмите меню Chrome с тремя точками.
3. Выберите **«Установить приложение»**. Если такой строки нет, выберите **«Добавить на главный экран»**.
4. Подтвердите установку. На главном экране появится иконка FocusList.
5. Открывайте FocusList через эту иконку — он будет запускаться в отдельном окне, почти как обычное приложение.

## Что важно знать

Веб-версия сохраняет данные браузера на устройстве. Она удобна для планирования и тестирования без Expo Go, однако не является заменой подписанного APK или AAB. Для публикации в Google Play по-прежнему используйте AAB из GitHub Actions.

Сервисный worker намеренно не кеширует интерфейс агрессивно: при следующем открытии пользователь получает актуальную версию приложения, а не устаревшую копию.
