# Подготовка FocusList к публикации

FocusList уже настроен как приложение Expo для портретной ориентации iOS и Android. Его идентификаторы пакетов сохраняются в `app.config.ts`, а иконки для iOS, Android, splash-экрана и веб-версии синхронизированы в каталоге `assets/images/`.

Новый фирменный знак FocusList объединяет галочку списка и направленное вперёд движение в яркой сине-фиолетовой форме с тёплым акцентом. Он используется как логотип проекта и синхронизирован для иконок iOS, Android, splash-экрана и веб-версии.

При первом запуске FocusList показывает приветственный экран с новым логотипом, тремя ключевыми преимуществами и кнопкой «Начать планировать». После нажатия приложение сохраняет выбор на устройстве и открывает рабочее пространство. Верхняя панель редактора папок использует безопасную область экрана, поэтому действия «Отмена» и «Готово» остаются ниже системного статус-бара.

После приветствия пользователь может пройти короткий мастер: создать свою первую папку, затем добавить в неё первую задачу с важностью и средним приоритетом. Оба шага можно пропустить. В настройках доступен сохранённый выбор из десяти популярных языков; переключатель задаёт предпочтение интерфейса и подготовлен для полного перевода текстов приложения.

Локализованы навигация вкладок, приветственный экран, мастер первого запуска, ключевые подписи главного экрана, настройки и выбор языка. Выбор языка доступен уже на первом приветственном экране, поэтому пользователь видит локализованный путь настройки до создания первой папки и задачи.

## Проверка перед отправкой

| Этап | Что проверить | Результат |
|---|---|---|
| Данные | Создать, изменить, завершить и удалить задачу; создать и изменить список | Изменения остаются после перезапуска приложения |
| Категории | Создать папку и несколько цветных тегов, назначить их задаче, затем удалить по очереди | Папка и теги показываются у задачи; после удаления связь корректно снимается |
| Поиск и фильтры | Найти задачу по названию, заметке или тегу; последовательно открыть три умных фильтра | Показаны только подходящие незавершённые задачи |
| Перенос | Удержать задачу в открытой папке и выбрать другую папку в меню | Задача исчезает из исходной папки и появляется в выбранной |
| Приоритеты | Создать задачи с высоким, средним и низким приоритетом, затем включить сортировку по приоритету | Задачи отображаются в порядке: высокий, средний, низкий, без приоритета |
| Архив | Завершить задачу, открыть «Архив» и нажать на её галочку | Задача появляется в архиве, затем возвращается в активный список с исходными свойствами |
| Глобальный поиск | Найти активную и архивную задачу по названию, заметке и тегу; сменить статус, тег и приоритет | Результаты соответствуют всем выбранным условиям |
| Недельная статистика | Завершить задачи в разные дни недели, затем открыть раздел «Недельная статистика» | Столбцы и итог отражают количество выполненных задач по дням |
| Стартовые папки | Открыть редактор новой задачи на чистой установке и проверить раздел «Папка» | Показаны «Дом», «Авто», «Работа» и «Личное» без повторов после перезапуска |
| Верхняя панель редактора | Открыть новую задачу на устройстве с вырезом или высоким статус-баром | «Отмена», заголовок и «Готово» находятся ниже системной области и доступны для нажатия |
| Иконки папок | Открыть «Организация», выбрать папку, затем открыть редактор задачи | Иконка папки видна в карточках, списке папок и селекторе; её можно сменить при редактировании папки |
| Эмодзи и закрепление | Изменить эмодзи папки, включить «Закрепить сверху» и вернуться в «Организацию» | Эмодзи отображается во всех представлениях; закреплённая папка стоит первой и помечена булавкой |
| Просроченные задачи | Создать задачу с прошедшим сроком внутри папки и открыть «Организацию» | На градиентной карточке папки отображается контрастный счётчик просроченных задач |
| Шаблоны папки | В открытой папке сохранить шаблон, затем нажать на него | В папке сразу создаётся новая задача с названием, заметкой, важностью и приоритетом шаблона |
| Градиентные обложки | Изменить папку и выбрать градиент в палитре | Карточка и верхняя область папки используют выбранную обложку |
| Управление папкой | Нажать «Редактировать» на карточке папки, изменить параметры, затем нажать кнопку удаления | Редактор открывается напрямую; удаление требует подтверждения, а связанные задачи остаются без папки |
| Первый запуск и редактор папок | Открыть чистую установку, нажать «Начать планировать», затем создать папку | Приветствие показывается только один раз; верхняя панель редактора папки расположена ниже статус-бара |
| Мастер и язык | На чистой установке пройти мастер, затем выбрать язык в настройках | Созданные папка и задача сохраняются; выбранный язык остаётся после перезапуска |
| Локализованный первый запуск | На приветственном экране выбрать язык, затем открыть главный экран и настройки | Навигация, мастер, главный экран и настройки используют выбранный язык |
| Статус и срок задачи | Открыть существующую задачу, отметить её выполненной, указать дату и время | Статус меняется из редактора; срок сохраняется с точностью до минут |
| Экран «Сегодня» | Создать задачи на сегодня, завтра, без срока и просроченную | На главном экране отображаются только незавершённые задачи со сроком на сегодня |
| Повторяющиеся задачи | Создать задачу с ежедневным или еженедельным повторением, затем отметить её выполненной | Исходная задача попадает в архив, а новый экземпляр появляется со сроком через 1 день или 7 дней |
| Сроки | Назначить дату в формате `ДД.ММ.ГГГГ`, затем открыть «Календарь» | Задача показана в выбранный день |
| Темы | По очереди выбрать светлую, тёмную и системную темы | Цвета интерфейса изменяются и сохраняются |
| Напоминания | Включить уведомления и создать будущую задачу со сроком | Устройство выдаёт запрос разрешения и запланированное напоминание |
| Нативная сборка | Установить сборку на реальное iOS- или Android-устройство | Поведение соответствует тестовому сценарию |

Локальные уведомления работают без сервера, однако разрешение на них пользователь выдаёт на уровне операционной системы. Для Android приложение заранее создаёт отдельный канал «Напоминания о задачах». Тестируйте напоминания на физическом устройстве: в среде Expo Go возможности удалённых push-уведомлений Android ограничены, а локальные напоминания остаются доступными. [1]

## Порядок публикации

После финальной проверки необходимо создать контрольную версию проекта, затем выбрать **Publish** в интерфейсе управления проектом. Эта операция запускает управляемую сборку, из которой можно получить пакет для тестирования и отправки в магазины. Не собирайте APK вручную в рабочей среде проекта.

Для публикации потребуются собственные учётные записи разработчика Apple и Google, название и описание приложения, скриншоты, политика конфиденциальности и заполнение возрастного рейтинга. Перед отправкой обновите номер версии в `app.config.ts` и проверьте магазинные требования к описанию и медиа-материалам.

> FocusList сейчас использует локальное хранение, поэтому персональные задачи не передаются на сервер и не синхронизируются между устройствами. Это следует явно отразить в политике конфиденциальности и карточках магазинов.
